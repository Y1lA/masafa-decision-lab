# مسافة — مساحة بين الفكرة والقرار

موقع عربي ثابت وتفاعلي يساعد الزائر على التفكير في قرار من مسار الإقدام ومسار الانتظار، ثم اختيار تجربة صغيرة قابلة للتراجع.

## ما يميّزه

- واجهة عربية كاملة من اليمين إلى اليسار، متجاوبة مع الهاتف.
- محاكاة تفكير تعمل محليًا في المتصفح بقوالب مخصّصة لما يقلق المستخدم؛ لا تتصل بخدمة توليد، ولا تحفظ المدخلات أو ترسلها إلى خادم.
- ستة مصادر قلق للاختيار، وأمثلة سريعة، ورؤى لأسبوع وستة أشهر، وخطوة عملية صغيرة، ونسخ خلاصة التجربة.
- بلا إطار عمل أو مفاتيح API أو ملفات تتبع.

## التشغيل محليًا

افتح `index.html` في المتصفح، أو شغّل خادم ملفات ثابتة:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

مهيّأ لـ GitHub Pages من فرع `main` ومجلد الجذر `/`؛ لا حاجة إلى build step.

## ملاحظة

النتائج أسئلة وتأملات عامة وليست تنبؤًا أو نصيحة مهنية أو مالية أو علاجية.
